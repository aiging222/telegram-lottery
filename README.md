# Telegram 可配置权重抽奖机器人

使用 Python 3.11+、python-telegram-bot 和 SQLite。群管理员在私聊里用按钮发起和管理本群抽奖（定时开奖或满人开奖），设置本群的灵石（签到和发言得的积分）；超级管理员另可用按钮或命令配置权重（个人权重、规则加成）。支持报名按钮（仅限发布群成员）、不重复抽奖、冻结快照及修改记录。

## 安装与启动

在本 README 所在目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m pip install --no-deps -e .
cp .env.example .env
```

也可以使用 [uv](https://docs.astral.sh/uv/)：执行 `uv sync` 按 `uv.lock` 创建 `.venv` 并安装项目和测试工具，再执行 `cp .env.example .env`。uv 创建的环境里没有 pip，下文命令改用 `uv run` 前缀，例如 `uv run python -m lottery.bot`。

如果项目位于 iCloud 同步的「文稿」或「桌面」目录，iCloud 会给 `.venv` 里的文件加上隐藏标记，Python 会跳过被隐藏的 `.pth` 文件，导致 `lottery-bot` 命令找不到 `lottery` 模块。解决办法是把环境建在 iCloud 不同步的 `venv.nosync` 目录，再用 `.venv` 链接过去：

```bash
uv venv venv.nosync
ln -s venv.nosync .venv
uv sync
```

使用 SOCKS 代理（例如 `ALL_PROXY=socks5://…`）时，依赖里已包含所需的 `python-telegram-bot[socks]`。

编辑本地 `.env`：

```dotenv
TELEGRAM_BOT_TOKEN=填写你的机器人令牌
ADMIN_USER_IDS=填写你的Telegram数字用户ID
DATABASE_PATH=data/lottery.sqlite3
TIMEZONE=Asia/Shanghai
```

- 通过 Telegram 官方 [@BotFather](https://t.me/BotFather) 创建机器人并获取令牌。令牌仅填写在本地 `.env`，不要提交到代码仓库。
- `ADMIN_USER_IDS` 是用户 ID，不是用户名、群 ID 或机器人的 ID；多个管理员用英文逗号分隔。
- 如果尚不知道自己的 ID，可临时将 `ADMIN_USER_IDS` 设为 `9223372036854775807`，启动后私聊机器人发送 `/id`，再将返回的真实 ID 填入配置并重启。这个临时值仅用于启动期间不授予实际用户管理权限；正式使用前必须替换。
- 在本目录运行；相对数据库路径以运行目录为基准。
- `TIMEZONE` 填 IANA 时区名（如 `Asia/Shanghai`、`America/New_York`），影响报名卡片上截止时间的显示，以及灵石签到按哪个时区的 0 点换天，并会自动处理夏令时；不填时默认 `Asia/Shanghai`（北京时间，UTC+8）。截止判断本身与时区无关。

```bash
python -m lottery.bot
```

启动后私聊机器人发送 `/start`，点「➕ 添加到群组」选择目标群，并把机器人设为群管理员，给它「置顶消息」「删除消息」「封禁用户」「邀请用户」四项权限（从「添加到群组」按钮进群时会自动勾选）：报名时机器人要向 Telegram 查询点击者是否在群内，成员退群时也要收到通知，这两件事 Telegram 只对管理员机器人保证；置顶和清理消息需要前两项权限，「封禁用户」用于把刷屏签到的人禁言 5 分钟，「邀请用户」用于给群友生成邀请抽奖的专属链接。已经在群里的机器人需要群主在管理员设置里补开「封禁用户」和「邀请用户」。机器人进群后会发一条带「⚙️ 管理抽奖」按钮的欢迎消息，之后在群里发送 `/start` 也会再发一条。

「📋 我的群」里，超级管理员看到机器人所在的全部群，群管理员看到自己管理的群。机器人进群时和每次启动时，会向 Telegram 取一次各群的管理员名单（`getChatAdministrators`）记下来；运行期间有人被设为或撤销管理员，机器人收到通知后也会跟着更新（这项通知需要机器人是群管理员）。启动时如果发现机器人已不在某个群里（比如离线期间被移出，或群已解散），这个群就不再列出。万一某个群没出现在列表里，在群里发送 `/start`，再点「⚙️ 管理抽奖」即可。

当前使用长轮询，不需要公网 Webhook 地址。各群、各人的消息并发处理，同一个人的操作按发出的先后依次处理。运行机器需要能访问 Telegram；同一令牌只运行一个轮询进程。停止进程后机器人不再响应，恢复运行后从数据库继续。

## 服务器常驻与更新

在 Linux 服务器上用 systemd 常驻运行：崩溃 5 秒后自动重启，开机自动启动。以下以系统用户 `lottery`、项目目录 `/home/lottery/telegram-lottery` 为例，只需配置一次。用 root 创建 `/etc/systemd/system/lottery-bot.service`：

```ini
[Unit]
Description=Telegram lottery bot
After=network-online.target
Wants=network-online.target

[Service]
User=lottery
WorkingDirectory=/home/lottery/telegram-lottery
ExecStart=/home/lottery/telegram-lottery/.venv/bin/python -m lottery.bot
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

然后执行 `systemctl daemon-reload` 和 `systemctl enable --now lottery-bot`。日志用 `journalctl -u lottery-bot -n 50 --no-pager` 查看。

以后更新代码，只需用 root 执行一条命令：

```bash
bash /home/lottery/telegram-lottery/scripts/update.sh
```

脚本会依次停止机器人、备份数据库（`.env` 里 `DATABASE_PATH` 指向的文件，用 SQLite 自带的备份功能连同 `-wal` 文件里的内容一起备份为同目录下的 `backup-时间.sqlite3`，保留最近 5 份）、拉取 `main`、按原来的安装方式安装锁定的依赖（`.venv` 里有 pip 就用 pip 安装 `requirements.lock`，否则用 `uv sync`）、重新启动，最后显示运行状态。中途任何一步失败，也会把机器人重新启动。数据库表结构在启动时自动升级。

## 谁能做什么

| 身份 | 能做的事 |
| --- | --- |
| 超级管理员（`.env` 的 `ADMIN_USER_IDS`） | 管理所有群的抽奖和灵石设置；独有中奖加成设置（按钮和命令）、`/rules`、预览、导出、修改发言次数、给人加减灵石、导出灵石流水 |
| 群管理员（群主或管理员） | 在私聊菜单里发起、截止、开奖、取消、重新发布**本群**的抽奖，修改本群的抽奖设置、灵石设置和邀请设置，查看邀请明细 |
| 群成员 | 点卡片上的「🎟 参与抽奖」报名，查看卡片和开奖结果；在群里签到、查灵石和灵石榜；领取自己的专属邀请链接并查看自己邀请了多少人（`/link`） |

群管理员身份每次都向 Telegram 实时查询（结果缓存 60 秒），查询失败时一律按“不是管理员”处理。被撤销管理员后最多 60 秒失去权限，这个群也会从其「📋 我的群」里消失。

## 群成员能看到什么

权重只有超级管理员能看到和修改。设置过规则加成或个人权重的抽奖，卡片上只显示「本场设有中奖加成」，不公布具体规则、谁有加成或任何人的权重；成员也不能查询自己的权重。这行字一旦出现就一直保留，即使之后撤回了加成，也不会在卡片上时有时无。

权重配置、完整名单预览和导出，只接受超级管理员在与机器人的私聊中操作；机器人不会将这些配置操作转发到群里。若你主动将配置指令发到群里，原始消息本身仍会被群成员看到，机器人拒绝执行并不等于消息被隐藏或撤回。

群内可见内容包括报名卡片（活动名称、奖品、中奖人数、已参与人数、开奖时间或满人条件、参与方式）、开奖结果和取消通知。开奖结果会 @ 中奖者，点名字可直接打开对方资料。

## 用按钮发起抽奖（群管理员）

1. 在群里点欢迎消息的「⚙️ 管理抽奖」，或私聊机器人 `/start` →「📋 我的群」，进入该群菜单。菜单显示进行中、已开奖、已取消的场数。
2. 点「➕ 发起抽奖」，先选类型：「🎟 普通抽奖」（下面的流程）、「🔥 群活跃抽奖」、「🪙 积分抽奖」、「🪁 邀请抽奖」或「🙋 指定群报道抽奖」（见后面几节）。然后按提示依次填写。每一步上方都会列出已经填好的内容；带按钮的步骤也可以直接发送文字回答。已经走过的步骤，旧消息上的按钮会提示已过期，不会改掉后面填好的内容。
   1. **奖品**：发送奖品名称（如 `1USDT`），再选或发送份数。
   2. **开奖方式**：
      - **定时开奖**：点 1小时～7天，或发送时间，如 `90分钟`、`2小时`、`3天`、`45`（分钟）、`2026-10-05 20:00`、`10-05 20:00`（按 `TIMEZONE` 解读；提示里会显示当前时间；不写年份时取离现在最近的那天，12 月填 `01-05` 即明年 1 月 5 日；算出来早于现在的时间直接报错，请你重新填写，明年的日期请写上年份）。时长不论点选还是发送，都从点「发布」时算起；填写的具体时间如果在发布前已经过了，点发布时会请你重新填写。到时间自动开奖。
      - **满人开奖**：选或发送人数，报名人数达到后立即开奖；7 天内没满也会在第 7 天自动开奖。
   3. **参与方式**：「🎟 点按钮参与」，或「💬 发口令参与」再发送口令（1～32 字，如 `帅哥`）。口令模式下卡片没有按钮，群友在群里发送口令即报名（不分大小写，前后空格不影响），报名成功时机器人给这条消息点一个 🎉。
   4. **活动名称**：发送名称，或点「用「奖品名」作名称」。
3. 确认页列出全部内容：
   - 「✅ 发布抽奖」把报名卡片发到群里；「❌ 取消发布」放弃；
   - 「➕ 添加奖品」再加一种奖品，最多 10 种、共 100 人；
   - 「🔄 换个群」改发到你管理的其他群。

   有多种奖品时，先抽出的人拿排在前面的奖品，开奖公告写明每人中的奖品。未完成的填写保存在数据库里，机器人重启后接着填；随时发送 `/cancel` 或点「✖ 取消」退出。
4. 「📜 抽奖记录」列出本群所有抽奖，点进一场可以：
   - 🎲 立即开奖：截止报名并开奖，结果发到群里；
   - ⏹ 截止报名：不再接受报名，到原定时间自动开奖；
   - ✖ 取消抽奖：未开奖的抽奖可以取消，群里会收到通知，卡片改为「已取消」，不可恢复；积分抽奖取消时，报名扣除的灵石全部退还；
   - 📣 重新发布：卡片被刷到上面或误删时，再发一张（仅报名中）。

这三个操作都要再点一次「✅ 确定」。群卡片上的参与人数会在有人报名或退群后几秒内自动更新，开奖、截止、取消后按钮自动消失。

## 群活跃抽奖（群管理员）

按群友在群里的发言次数决定中奖，不用报名：群卡片上写明规则，没有报名按钮，在群里发言就算参与。「➕ 发起抽奖」→「🔥 群活跃抽奖」后有两种：

- **1️⃣ 根据活跃排名抽奖**：依次填写开始统计的时间、开奖时间、第一名奖品、第二名奖品……（最多 10 个名次，点「👉 结束添加奖品，进入下一步」结束）、活动名称，然后发布。开奖时按发言次数排名，第一名拿第一名的奖品，依此类推。
- **2️⃣ 达到发言次数参与随机抽奖**：依次填写开始统计的时间、开奖时间、至少发言几次、奖品和份数、活动名称。开奖时在发言次数达到要求的人里随机抽取。

规则：

- **开始统计的时间**：发送 `0`（或点「▶️ 从发布时开始」）从发布时开始统计；也可以发送过去的时间，如 `2026-09-30 18:41`，最早 30 天前；不写年份时取离现在最近的那天，1 月初填 `12-31 18:00` 即去年 12 月 31 日。统计到开奖时间为止，按分钟计。
- **只统计有效发言**：文字和带文字说明的图片、视频等，除去空格至少 3 个字，且距这个人上一条有效发言 5 秒以上，才算一次（字数和间隔在「💎 灵石设置」里改，和灵石的发言奖励共用）。贴纸、不带说明的图片、命令，「签到」「灵石」「我的灵石」「灵石榜」，以及机器人、频道和匿名管理员发的消息都不算。这条规则从灵石功能上线起生效，之前已经统计的次数不变。
- **排名**：发言多的排前面；次数相同时，先达到这个次数的排前面。已经退群的人不参与（之后重新入群并再发言的照常参与）。
- **查看排名**：卡片上有「📊 查看我的排名」按钮，群友点了会弹出只有自己看得到的提示，不会在群里刷屏。排名抽奖显示当前前 5 名和自己的名次、发言次数；达标抽奖显示已达标人数和自己还差几次。排名每 30 秒最多算一次，这段时间里谁点都看到同一份，所以刚发的言最多晚 30 秒才算进去；上万人的大群里很多人同时点也不会拖慢机器人。这个按钮是后来加的，更早发出的活跃抽奖卡片没有它，在抽奖记录里点「📣 重新发布」即可换上新卡片。
- **开奖公告**写明每位中奖者的发言次数，如 `1. 张三 — 1usdt（发言 128 次）`。
- **修改发言次数**（超级管理员）：机器人因为网络中断等原因漏记时，在「抽奖记录 → 某场活跃抽奖 → ✏️ 修改发言次数」里补上。点成员后用 +1/+5/+10/-1/-5/-10 调整，或点「✏️ 改为…」发送正确的总次数，「↩️ 清除修改」撤销；名单里没有的人用「➕ 按用户 ID 修改」发送 `用户ID 次数`。修改加在机器人统计的次数上，之后的发言照常累计；统计截止后不能再改；已退群的人改了也不参与。群里的排名和开奖公告显示修改后的次数，看不出修改过；每次修改记入修改记录，导出文件和 `/preview` 会标明手动改了多少。
- 群活跃抽奖不能设置权重或指定获奖。超级管理员可以用 `/preview ID` 看当前排名，在抽奖记录里导出完整记录。

机器人只能统计它自己收到的消息：需要是群管理员（或在 @BotFather 关掉隐私模式）才能收到群里所有消息，而且只能从本功能上线后开始统计，更早的发言查不到。发起时的提示会显示本群从什么时候开始有记录。发言次数先在内存里累计，每 10 秒存入数据库，停机时也会存盘；超过一个月的记录会自动清理（仍在进行的活跃抽奖需要的除外）。

## 群抽奖设置（群管理员）

群菜单里的「⚙️ 抽奖设置」按群分别设置。两个置顶设置点一下在开、关之间切换；两个删除设置点开后选一个时间，或直接发送分钟数（0～1440，0 表示立即删除）。页面顶部会显示机器人有没有「置顶消息」「删除消息」权限，缺哪个就提示群主去开。缺权限时对应功能跳过，报名和开奖照常进行。

| 设置 | 默认 | 可选 | 说明 |
| --- | --- | --- | --- |
| 📌 置顶报名卡片 | 开 | 开 / 关 | 发布时静默置顶（不通知群成员），开奖或取消后取消置顶；重新发布时置顶移到新卡片。机器人没有「置顶消息」权限、没能置顶时，发布（或重新发布）后的提示会写明，补开权限后在抽奖记录里点「📣 重新发布」 |
| 📌 置顶开奖公告 | 开 | 开 / 关 | 静默置顶开奖公告；每个群只保留最新一条，上一条自动取消置顶 |
| 🧹 删除口令消息 | 1 分钟后 | 立即 / 3 秒后 / 1 分钟后 / 5 分钟后 / 10 分钟后 / 1 小时后 / 不删，或发送 0～1440 分钟 | 群友发的口令消息（包括重复发送的）。选「立即」时不再点 🎉 |
| 🗑 删除机器人通知 | 3 秒后 | 同上 | 欢迎消息、群里 `/start`、`/help`、`/id` 及其回复、取消通知、群里用错命令或操作出错时的提示及那条命令、灵石的签到和查询（连同群友发的那条）及发言奖励的回复。带「⚙️ 管理抽奖」按钮的欢迎消息和群里的 `/start` 至少保留 1 分钟，让管理员来得及点；`/help`、`/id` 的回复也至少保留 1 分钟，方便看完或复制。报名卡片和开奖公告不会被删 |

页面底部显示最近一次修改（谁、什么时候、把哪一项从什么改成什么），「📜 修改记录」列出最近 15 次修改。同一个群的所有管理员共用一份设置，谁改了其他人都会看到。

待删除的消息记在数据库里，每 30 秒处理一次，机器人重启后照样会删；1 分钟以内到期的（比如 3 秒后）另外按秒准时删。Telegram 只允许机器人删除 48 小时内的消息，停机超过这个时间，过期的消息就不再删除。网络出错会下次重试；没有权限或消息已不存在则放弃。

## 邀请抽奖（群管理员）

按群友拉进群的新成员人数决定中奖，不用报名。「➕ 发起抽奖」→「🪁 邀请抽奖」后：

1. 选邀请方式：
   - **🔗 专属链接邀请**：机器人给每个群友生成一条只属于他的进群链接，别人通过这条链接进群就算他邀请的。群友点卡片上的「🔗 领取我的邀请链接」会跳到和机器人的私聊，机器人把链接发在私聊里；也可以在群里发送 `/link`，机器人在群里回复链接（至少保留 1 分钟方便复制，然后按删除设置删掉）。每个群友的链接各不相同，机器人记着每条链接是谁的，所以能认出新成员是谁拉进来的；同一个人再领取还是他自己那条。链接默认不设有效期、不限人数，可以在「🔗 邀请设置」里改（见下一节）。
   - **⚠️ 添加成员邀请**：群友用「添加成员」直接把人拉进群，算拉人的人邀请的。群里要允许普通成员添加成员；这种方式容易拉小号刷人数。
2. 选玩法：
   - **🏆 邀请排名抽奖**：开奖时间 → 第一名、第二名……的奖品 → 活动名称。开奖时邀请最多的拿第一名的奖品，依此类推。
   - **🎯 邀请次数抽奖**：至少邀请几人 → 定时开奖或满人开奖 → 开奖时间或满多少人达标 → 奖品和份数 → 活动名称。开奖时在邀请人数达标的人里随机抽取；选满人开奖的话，达标的人数一凑够就立即开奖（7 天内没凑够也会在第 7 天开奖）。

规则：

- **从抽奖发布时开始统计**，只算发布之后进群的人，不用先清空邀请数据。只统计选定的那种邀请方式。
- **每人只算一次**：只有机器人第一次见到的新成员才算。以前在群里发过言、有过灵石、退过群或者已经被邀请过的人，再被拉进来都不算。自己用自己的链接进群也不算。
- **开奖前退群的不算**：被邀请的人在开奖前退群，这个邀请就不算了，之后再回来也不补。邀请人自己退群，也不参与排名（回来之后照常算）。
- 群卡片上有「📊 查看我的邀请」，点了弹出只有自己看得到的前 5 名和自己的名次，或者还差几人；专属链接方式另有「🔗 领取我的邀请链接」。群里发 `/link` 也能看到自己在每场进行中的邀请抽奖里邀请了几人。开奖公告写明每位中奖者邀请了几人，如 `1. 张三 — 1usdt（邀请 5 人）`。
- 邀请抽奖不能设置权重或指定获奖，也不能手动修改邀请人数。超级管理员可以用 `/preview ID` 看当前排名，在抽奖记录里导出完整记录。

机器人要是群管理员才能收到成员进群的通知，并需要「邀请用户」权限才能生成链接；少了哪个，这种邀请就记不上。只有机器人自己生成的链接能认出是谁的，群主或管理员在群设置里生成的链接不算。群从普通群升级为超级群后，旧链接作废，群友重新领取即可。

**链接失效与重置**：
- 机器人被取消管理员、被收回「邀请用户」权限或被移出群时，Telegram 可能会让它生成的链接作废。机器人一旦发现这些情况，就给本群换新链接：之后群友再领取会拿到新链接。
- 群主在群设置里手动撤销了机器人生成的链接时，机器人收不到通知。这时在「🔗 邀请设置」里点「🔗 重置邀请链接」，确认后群友再领取就会拿到新链接。
- 换新链接时，机器人不会撤销旧链接，也不会忘记旧链接是谁的：旧链接要是还能用，通过它进群照样算原来那个人邀请的，已经算上的邀请人数也不受影响。

## 邀请设置（群管理员）

私聊菜单里选群后点「🔗 邀请设置」。页面上方显示状态、邀请提醒、总邀请人数（现在还在群里的；退群的另外注明）、链接有效期、每条链接最多邀请人数、生成数量上限、已生成数量，以及机器人有没有「邀请用户」权限和最近一次修改。防作弊规则和邀请抽奖一样：只有机器人第一次见到的新成员算有效邀请，进过本群的人退群后再用别人的链接进群不算，被邀请的人退群了也不算。

- **🔗 /link 领取链接**（默认开）：群友在群里发 `/link`（或私聊领取）拿到自己的专属链接。关闭后机器人回复「本群没有开启邀请链接。」；但本群有进行中的专属链接邀请抽奖时，照常可以领取，否则那场抽奖没法进行。
- **`/link` 的回复**：链接本身（设了有效期或人数上限时一并写明），然后是「📊 你已邀请 N 人」——清空数据以来他邀请进群、现在还在群里的人数，用链接和被拉进群的都算；本群每场**进行中**的邀请抽奖再各占一行，按那一场的规则写他邀请了几人，达标抽奖还写差几人达标。已经结束的抽奖不显示。
- **📣 邀请提醒**（默认关）：有人第一次进群、算作某个群友邀请的时候，机器人在群里发一条「🎉 小明 通过 张三 的邀请链接进群，张三 已邀请 5 人。」（被拉进群的写「张三 把 小明 拉进了群」）。这条至少保留 1 分钟，再按「🗑 删除机器人通知」的时间删；这一分钟里机器人在群里发的消息太多时就不发了。
- **🔧 链接有效期 / 每条链接最多邀请 / 生成数量上限**：点按钮选，或者直接发送数字，0 表示无限制。
  - 改了有效期或每条链接最多邀请人数后，群友再领取会拿到按新设置生成的链接；已经发出去的旧链接保持原来的设置，照常能用，通过它进群也照样算原来那个人邀请的。
  - 链接过期或用满（机器人按通过它进群的人数计算）后，群友再领取会自动换一条新链接；离过期不到 1 小时的也会换。
  - 生成数量上限算的是上次清空数据以来机器人生成的链接，换掉的旧链接也算。到了上限，手里链接还能用的人照常领取，需要新链接的人会被提示联系群管理员。
- **👥 邀请明细**：列出邀请过人的群友，按现在还在群里的人数排序，并标出其中退群了几人、他本人是否已经退群；点一个人，列出他邀请的每个人的名字、用户 ID、进群时间、进群方式（用链接/被拉）以及是否已退群。邀请抽奖在「📜 抽奖记录」里也有「👥 邀请明细」，按那一场的规则（统计开始时间、邀请方式、开奖前退群的不算、邀请人自己退群的不算）列出。本功能上线前的邀请记录没有存被邀请人的名字，这些人显示他在群里发言或领灵石时用的名字。
- **🖨 导出**：把 JSON 文件发到私聊，里面有本群全部邀请记录（包括清空前的）、机器人生成的每条链接（谁的、有效期、人数上限、通过它进群的人数、是否已换掉），以及设置的修改记录。
- **🔗 重置邀请链接**：见上一节「链接失效与重置」。
- **🗑 清空数据**：确认后，总邀请人数、已生成数量、`/link` 里的邀请人数和邀请明细都从现在起重新统计。防作弊的记录会保留，以前进过群的人再进群仍然不算有效邀请；进行中的邀请抽奖按各自的规则统计，不受影响；已经发出去的链接照常能用；清空前的记录仍在导出文件里。
- 每次修改（包括清空数据）都记入「📜 修改记录」。

## 指定群报道抽奖（群管理员）

把本群的人引到另一个群（报道群）去：本群成员加入报道群即可参与，不用发口令。「➕ 发起抽奖」→「🙋 指定群报道抽奖」，看完说明点「▶️ 继续」，然后：

1. **指定报道群**：点按钮从你管理、机器人也在的其他群里选；或者发送报道群的链接，如 `https://t.me/xxx` 或 `@xxx`。发链接只支持公开群（私密群的邀请链接机器人认不出是哪个群），而且同样必须是你管理、机器人已经在里面的群。
2. 后面和普通抽奖一样：奖品和份数 → 定时开奖或满人开奖 → 开奖时间或满多少人 → 活动名称 → 发布。

规则：

- 报名卡片和开奖公告只发在本群。卡片写「👉 加入「报道群」即可参与」，带「➡️ 进入报道群」（公开群用它的 @ 链接，私密群用机器人在报道群生成的邀请链接）和「✅ 我已加入报道群」两个按钮。
- **本群成员进入报道群时自动报名**，不用做别的。不是本群成员的人进报道群不会报名。
- **原来就在报道群里的**本群成员，点卡片上的「✅ 我已加入报道群」报名；机器人查他在不在两个群里，不在报道群的会提示先加入。
- **开奖前退出任一个群都会取消报名**。
- 超级管理员同样可以设置中奖加成和指定获奖。

两个群都要把机器人拉进去并设为管理员：机器人要是报道群的管理员才收得到有人进群的通知，否则只能靠群友点按钮报名；报道群是私密群时，机器人还要有「邀请用户」权限才能生成进群链接，没有的话卡片上就没有「➡️ 进入报道群」按钮。

## 积分抽奖（群管理员）

用灵石报名的抽奖：群友报名时从本群的灵石里扣除设定的数量（灵石的获得方法见后面「灵石」一节）。「➕ 发起抽奖」→「🪙 积分抽奖」后：

1. 先选「⏰ 定时开奖」或「👥 满人开奖」（「⬅️ 返回选择抽奖类型」可以换类型）。
2. 发送奖品名称，再选或发送份数。
3. 定时开奖填开奖时间，满人开奖填满多少人，写法和普通抽奖一样。
4. **参与需要多少灵石**：点 10/20/50/100，或发送 1～1000000 的数字。本群关闭了灵石功能时会提醒你群友现在得不到灵石。
5. 参与方式：点按钮参与，或发口令参与。
6. 活动名称，确认后发布。确认页同样可以加奖品、换群；超级管理员同样可以设置中奖加成和指定获奖。

规则：

- 卡片写明「🪙 参与需 20 灵石，报名时扣除」，按钮是「🎟 参与抽奖（20 灵石）」。
- **每人报名一次，扣一次**。点按钮时弹出只有自己看得到的结果，如「报名成功，扣除 20 灵石，剩余 35 灵石。」；灵石不够时提示「灵石不足：参与需要 20 灵石，你有 5 灵石。」，不能报名。已经报过名的再点不会重复扣。
- 口令报名时，机器人回复这条口令说明扣了多少或为什么没报上，回复按「🗑 删除机器人通知」的时间删除。
- 扣除和报名同时成功或同时失败，不会只扣灵石不报名。每笔扣除记入灵石流水，写明是哪场抽奖。
- **取消抽奖时全额退还**报名扣除的灵石，群里的取消通知会写明。开奖后不退（中奖和没中奖都不退）。
- 截止前退群的人报名被取消，灵石按退群规则清零，不退还。

## 灵石（群管理员设置，群友使用）

灵石是按群分开计算的积分：同一个人在不同群里的灵石互不相通。群友在群里直接发送下面这些词（不用 @ 机器人）：

| 发送 | 作用 |
| --- | --- |
| `签到`、`/签到` 或 `/checkin` | 每天签到一次，默认得 10 灵石。回复 `✅ 签到成功，获得 10 灵石`、当前余额和今天第几个签到。按 `TIMEZONE`（默认北京时间）的 0 点换天。`/checkin` 列在群里输入框的「/」命令菜单里，点一下就能签到（Telegram 的命令只能用英文，所以「/签到」进不了菜单）；关了灵石功能时，`/checkin` 回复「本群的灵石功能已关闭。」 |
| `灵石` 或 `我的灵石` | 查看自己的灵石、今天签到没有、今天领了几次发言奖励 |
| `灵石榜` | 本群灵石最多的前 10 名，以及自己的名次 |

- **发言奖励**：每条有效发言（见「群活跃抽奖」里的规则：至少 3 个字、间隔 5 秒以上）有 5% 的概率得 5 灵石，平均约 20 条一次，每天不限次数（可以设上限）。得到奖励时再单独有 10% 的概率暴击，得 2 倍。得奖时机器人在群里回复这条发言，如 `💬 张三 活跃发言，获得 5 灵石` 或 `⚡ 暴击！张三 活跃发言，获得 10 灵石`，不写今天第几次。签到没有暴击。奖励概率和暴击率只在「💎 灵石设置」里给管理员看，群友查询灵石时只看到今天领了几次和「多发言就有机会获得」。
- **自动删除**：签到、查询的回复和群友发的那条消息，以及发言奖励的回复，都按「⚙️ 抽奖设置」里「🗑 删除机器人通知」的时间删除（默认 3 秒后，群友看一眼就消失，群里保持干净）。群友的普通发言不删。
- **灵石面板（人多的群推荐）**：在「💎 灵石设置」里点「📌 发布灵石面板」，机器人在群里发一条带「📅 签到」「💎 我的灵石」「🏆 灵石榜」按钮的消息并置顶；再发一次会换成新面板，旧的取消置顶并删除（超过 48 小时的旧消息删不掉，但按钮照样能用）。群里可以同时置顶好几条，顶部横条只显示最新置顶的那条，面板会被之后置顶的报名卡片、开奖公告挤到后面（点横条可以切换到它，按钮照样能用）。所以每场抽奖结束（开奖公告置顶后，或者抽奖被取消后），机器人会自动重发一次面板放回最上面；群里还有别的抽奖在进行、报名卡片还置顶着时先不放，等最后一场结束再放。没发过面板、关了灵石功能、或者两个置顶设置都关了的群不会自动发；机器人没有置顶权限时，新面板撤回，旧面板保留。管理员自己置顶的消息，机器人不会去抢位置。群友点按钮，结果立刻弹出，只有自己看得到，机器人不在群里发任何消息，所以不受下面说的每分钟 20 条限制，群里也不会被签到刷屏。签到按钮会先向 Telegram 确认点的人是本群成员（每人每天只查一次）；弹窗最多 200 字，灵石榜在弹窗里只列前 5 名。和发文字「签到」是同一次签到，用哪种都行。
- **发送额度**：Telegram 只允许机器人在同一个群每分钟发约 20 条消息。机器人自己记着数，一分钟内在这个群已经发了 15 条时，发文字「签到」「灵石」等改为给那条消息点表情，不回文字：签到成功 👍、今天已经签过 👌、查询 👀、没开启签到或加减失败 🤷；发言奖励改为点 🎉（暴击 ⚡）。灵石照常加，群友发的那条消息照常按时删除；过一分钟有了额度就恢复文字回复。留出的 5 条给抽奖卡片和开奖公告。群里关闭了表情回应时，这段时间就没有任何回应。
- **签到刷屏**：今天已经签到的人 1 分钟内再发签到，前 3 次回复「今天已经签到过了」，第 4 次回复「已签到，频繁发送将导致账号禁言」，第 5 次起禁言 5 分钟（到时 Telegram 自动解除）。机器人没有「封禁用户」权限，或对方是群管理员时，只警告不禁言。
- **退群清零**：成员退群、被踢或被封禁时，这个群里的灵石清零（记入流水），重新入群后从 0 开始；当天已经签到过的，当天不能再签。机器人需要是群管理员才能收到退群通知。

群菜单里的「💎 灵石设置」（群管理员和超级管理员）：

| 设置 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 💎 灵石功能 | 开 | 开 / 关 | 关闭后群友发签到等不再回应，发言也不奖励；已有的灵石保留 |
| 📅 签到 | 10 灵石 | 0～10000 | 0 表示关闭签到 |
| 🎲 奖励概率 | 5% | 1～100 | 每条有效发言获得发言奖励的概率 |
| 🎁 发言奖励 | 5 灵石 | 0～10000 | 0 表示不奖励发言 |
| 🔁 每天最多 | 不限 | 0～1000 | 每人每天最多领几次发言奖励；0 表示不限 |
| ⚡ 暴击率 | 10% | 0～100 | 得到发言奖励后，这次奖励暴击的概率；0 表示没有暴击 |
| ✖️ 暴击倍数 | 2 倍 | 2～10 | 暴击时奖励翻几倍 |
| ✍️ 最少字数 | 3 字 | 1～100 | 有效发言至少几个字（不算空格）；**群活跃抽奖也按这个统计** |
| ⏱ 发言间隔 | 5 秒 | 0～3600 | 距上一条有效发言至少几秒；0 表示不限；**群活跃抽奖也按这个统计** |

点一项后选常用值，或直接发送数字。页面上还会显示机器人有没有「封禁用户」权限。设置按群分开，同一个群的所有管理员共用一份：一个管理员关了，这个群就关了。页面底部显示最近一次修改，如 `🕘 最近修改：01-15 16:01 李四：💎 灵石功能 开 → 关`；「📜 修改记录」列出最近 15 次修改（群管理员也能看）。

超级管理员在这一页另有两个按钮：

- **✏️ 修改余额**：按余额从高到低列出有灵石的成员，点成员后用 +10/+50/+100/-10/-50/-100 加减，或点「✏️ 输入数量」发送 `+50`、`-20`。列表里没有的人：
  - 「🔍 按名字查找」：发送名字里的几个字（英文不分大小写），列出本群里名字匹配的人，点一个就能加减。机器人认识在群里发过言或有灵石的人，余额为 0 的也能找到；结果最多列 10 个，可以接着发别的名字再找。
  - 「➕ 按用户 ID 修改」：发送 `用户ID 数量`，如 `123456789 +50`。
- **在群里回复加减**：超级管理员在群里回复某个成员的消息，发 `加灵石 50` 或 `扣灵石 20`（也可以写成 `加50灵石`、`扣20灵石`；整条消息只能是这几个字，「我加50灵石」这样带别的字的不算），机器人回复「✅ 已给 张三 加 50 灵石，现有 80 灵石。」，这条命令和回复按「🗑 删除机器人通知」的时间删除。只认 `ADMIN_USER_IDS` 里的超级管理员（不能用匿名管理员身份发），其他人发了没有反应；这类消息不算发言。

不用写原因；余额不能扣成负数；每次加减都记入流水。
- **📄 导出流水**：把本群每人的余额、全部设置修改记录和全部流水（签到、发言奖励、暴击、手动加减、退群清零、积分抽奖报名扣除和取消退还，含时间、变化、变化后余额、相关抽奖和操作人）作为 JSON 文件私聊发给你。

灵石可以用来报名积分抽奖，见上一节。

## 用按钮设置中奖加成（超级管理员）

以下按钮只有 `ADMIN_USER_IDS` 里的超级管理员看得到，群管理员和参与者都看不到。

- **发起时打开**：超级管理员走发起向导时，确认页多一个「⚖️ 中奖加成：关」按钮，点成「开」再发布，卡片从一开始就带「本场设有中奖加成」。报名进行中才第一次设置加成的话，这行字会在中途出现在卡片上。
- **设置每个人的权重**：「抽奖记录 → 某场抽奖 → ⚖️ 中奖加成」列出参与者的权重和首轮中奖概率，例如 `Alice · 权重 3 · 概率 75%`（概率 = 自己的权重 ÷ 全部参与者的权重之和）。点某人可选 `0 排除 / 1 / 2 / 3 / 5 / 10 / 其他`，或「↩️ 恢复默认」。
- **预设未报名的人**：「➕ 按用户 ID 设置」发送 `用户ID 权重`（如 `123456789 5`），对方报名后自动生效，名单里显示为「（未报名）」。
- **指定获奖**：在已报名成员的页面点「🎯 指定获奖」，开奖时该成员直接中奖，不参与随机抽取；再点「↩️ 取消指定」撤销。指定人数不能超过中奖人数；截止前退群，指定随报名一起取消。开奖时被指定的人排在最前面，拿排在前面的奖品，其余名额再按权重抽取。卡片和开奖公告上都不显示，也不会让卡片出现「本场设有中奖加成」；只有修改记录和导出文件里能看到谁被指定。页面上其他人的概率会按剩下的名额重新计算。
- **默认与上限**：「⚙️ 默认与上限」发送 `默认权重 上限`（如 `1 100`）。
- **导出**：「📄 导出记录」把完整名单、权重、快照和修改记录作为 JSON 文件私聊发给你。

报名截止后权重锁定，页面只显示最终权重。所有修改和命令一样记入修改记录。

## 用命令配置权重（超级管理员）

按钮能完成大部分设置；规则标签（按条件批量加成，如 vip +2）目前只能用命令。抽奖 ID 见记录里标题后的 `#数字`。也可以完全用命令创建和发布：

先在超级管理员与机器人的私聊中发送：

```text
/new 3 60 周末抽奖
```

表示创建抽取 3 人、60 分钟后截止的抽奖。机器人返回实际抽奖 ID，下面以 `1` 为例；用户 ID `123456789` 也需要替换为实际值。

```text
/config 1 1 100
/rule 1 vip 2
/rule 1 task_done 3
/grant 1 123456789 vip
/weight 1 123456789 10
/preview 1
```

然后在目标群发送：

```text
/publish 1
```

首次在群里 `/publish` 会把抽奖绑定到该群，之后只有该群的当前成员能报名。绑定后不能再发布到其他群（开奖结果不受限制）；发错群时请新建抽奖。普通群升级为超级群后群 ID 会变，机器人会自动跟随：旧群里的卡片无法再更新，报名中的抽奖会在升级后的群里重新发一张卡片。

参与者点击「🎟 参与抽奖」。**到截止时间后不需要任何操作**：机器人每 30 秒检查一次，会在截止后半分钟内自动开奖，并把结果发到发布群。

如需提前结束，先私聊发送 `/freeze 1` 截止报名（不可撤销），再发送 `/draw 1` 立即开奖；也可以只截止报名，等到原定时间自动开奖。每场抽奖的结果只在发布群公布一次：在发布群里手动 `/draw` 后不会再自动发送；在私聊里 `/draw` 的结果会在半分钟内自动补发到发布群。结果保存在数据库中，重复 `/draw 1` 或断网后重试都返回相同结果，不会重新抽取中奖人。

## 权重与开奖规则

```text
有个人覆盖值：最终权重 = 个人覆盖值
无个人覆盖值：最终权重 = min(默认权重 + 已授予的规则加成之和, 权重上限)
```

- 所有权重均为非负整数，上限最大 1,000,000。个人覆盖值也不能超过本场上限。
- 权重 `0` 表示不参与抽取；`auto` 表示取消覆盖，两者不同。
- 可以在报名之前按用户 ID 设置权重或授予条件；这些操作不会替用户报名。
- 一人同一规则最多生效一次；不同规则加成相加。
- 更新规则会影响所有拥有该条件的参与者，个人覆盖值仍然优先。
- 比如权重为 1、3、6，首轮概率分别为 10%、30%、60%。每抽出一人就移除该人，再按剩余权重抽下一人。
- 多名中奖者的最终中奖概率不能直接用首轮概率乘以名额。
- 被指定获奖的人先占名额（不看权重），其余名额再在其他人中按上面的规则抽取。
- 名额支持 1～100；正权重人数不足时抽取全部符合条件者，并在公告说明实际人数；无有效参与者时保存“0 人中奖”的结果。
- 抽奖彼此独立，不共享个人覆盖或已授予条件。

## 截止、快照与数据

到截止时刻，即使机器人曾离线，任何新的报名、规则修改和个人权重修改都会被拒绝。到期后首次读取或开奖时写入冻结快照；也可以提前 `/freeze`。

已在群里发布的抽奖到截止时间自动开奖，满人开奖的抽奖在最后一人报名成功时立即开奖，结果都发到发布群；名额满后再点报名会提示“名额已满”。从未发布到群的抽奖没有人能报名，不会自动开奖，需要时可手动 `/draw`。公告发送失败会在下一轮重试，名单长到分几条发送时从失败的那条接着发，置顶第一条；机器人已被移出群等无法发送的情况会记录日志并停止重试，结果仍然保存，超级管理员可用 `/result` 查询，群管理员可在抽奖记录里查看。升级到这个版本时已经过了截止时间的抽奖不会被自动补发公告。

采用 SQLite `BEGIN IMMEDIATE` 事务串行化写入，并开启 WAL（预写日志）模式，读和写互不等待。快照、结果和开奖记录一起提交；并发开奖只能提交一份结果。随机抽取使用 Python `secrets.randbelow`，按整数权重划分区间，无浮点随机边界问题。

每次管理操作保存操作人、时间和变更内容；规则、默认配置、个人覆盖保存修改前后值。重复授予已有条件、撤销不存在的条件，以及把规则、默认配置、个人权重设成原来的值，都不产生记录，机器人会回复“未做修改”。冻结快照包括参与名单、规则、个人权重和计算结果，SHA-256 摘要用于检查快照是否一致；摘要不在开奖公告里显示，可在 `/export` 导出的文件中查看。摘要不是公开可验证的随机性证明，数据库文件本身也不是防管理员篡改的审计系统。

数据库默认保存在 `data/lottery.sqlite3`。WAL 模式下，机器人运行时旁边还会有 `lottery.sqlite3-wal` 和 `lottery.sqlite3-shm` 两个文件，最近的改动先写在 `-wal` 里，不要删。正常停止机器人后，这两个文件会合并回主文件并消失。手动迁移或备份时先停止机器人，确认这两个文件已经没有了再复制数据库文件及配置；如果它们还在（比如机器人是崩溃退出的），就三个文件一起复制，或者用更新脚本里的备份方式。不要删除数据库后期待找回历史结果。

表结构版本记录在 SQLite 的 `PRAGMA user_version` 中。机器人启动时按顺序执行 `lottery/core.py` 里 `MIGRATIONS` 列表中尚未执行的迁移，全部在同一个事务内完成，失败则整体回滚。修改表结构时只在列表末尾追加新迁移，不要改动已发布的迁移。升级前建议先备份数据库文件。

## 第一版范围

- 条件由管理员核验后使用 `/grant` 授予；尚未接入自动验证入群、邀请数、付费或任务完成情况。
- 报名仅限发布群的当前成员：每次点击报名都通过 Telegram `getChatMember` 实时查询，查询失败时拒绝报名。口令报名的人已经在群里发言，不再查询；以频道或匿名管理员身份发的口令不算报名。
- 口令报名要求机器人是群管理员，否则 Telegram 不会把普通群消息转给机器人。群里禁用了表情回应时，报名照样成功，只是没有 🎉。
- 名单冻结前（截止或 `/freeze`）退群、被踢出或被封禁，会自动取消报名并记入修改记录；重新入群后可以再次报名。以退群发生的时间为准：机器人离线期间的退群，只要发生在截止前、且名单尚未冻结，恢复运行后仍会生效。名单冻结后退群不影响开奖。Telegram 最多保留 24 小时内的更新，离线更久可能漏掉退群事件。
- 不提供多账号识别。
- 群管理员只能通过按钮管理本群抽奖，不能配置权重；权重相关操作只开放给 `ADMIN_USER_IDS` 里的超级管理员。
- 支持私聊和群聊；不提供频道内匿名管理命令流程。
- 群卡片由机器人自动编辑更新；重新发布后只更新最新一张，旧卡片的按钮在截止后仍会拒绝报名。
- 不自动发奖，不处理资金。未开奖的抽奖可以取消；已开奖的不能重新抽奖或撤销。
